# Битва сладостей

Телеграм-бот + мини-приложение (Telegram Web App): турнир из 12 сладостей на выбывание.

## Мини-приложение

`index.html` — статическая страница, публикуется через GitHub Pages: https://mlasik.github.io/food_/

Экраны:
- меню: «Выбери любимое» и заблюренная карточка «Скоро!»;
- игра: пары «карточка vs карточка», хот-бар сверху с номером раунда и полоской прогресса;
- победитель.

### Картинки

Положите файлы в папку `images/` со следующими именами (jpg):

`kinder`, `kitkat`, `white-chocolate`, `milkyway`, `twix`, `zefir`, `iriski`,
`milk-chocolate`, `orange-lollipop`, `salted-caramel`, `cherry-buns`, `snickers-white`,
плюс `menu-sweets.jpg` для карточки меню.

Если файла нет, карточка показывает эмодзи-заглушку.

## Бот

```bash
pip install -r requirements.txt
BOT_TOKEN=<токен от @BotFather> python bot.py
```

`/start` отправляет «Привет @user, поиграем?» с кнопкой, открывающей мини-приложение,
и настраивает кнопку меню слева от поля ввода.

Переменные окружения:

- `BOT_TOKEN` — обязательный токен бота;
- `WEBAPP_URL` — адрес мини-приложения (по умолчанию ссылка на GitHub Pages).

Токен в репозитории не хранится.
